# AlertCardProof

Development proof for the HD2Runtime 0.30.2 custom stratagem alert card. Shows sample cards on demand:
Ctrl+F9 (amber, CHECK BEFORE LAUNCH), Ctrl+F10 (red, WILL FAIL, five problems), Ctrl+F11 (green, READY). Nothing
of the game is written. Report whether the card is visible, readable and well placed, aboard the ship and in a
mission.
