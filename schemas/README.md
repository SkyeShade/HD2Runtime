# Reviewed profile

`current.lua` is generated by `scripts/import_fixtures.py`. The profile contains
EXE/DLL fingerprints, the entity allocation extent, complete component framing,
index/record capacities, strides, expected resource rows and membership lists,
grouped settings framing, and checked module-relative stratagem locator leads.
There are no current-process absolute addresses in the profile.

Supported families are EntitySettingsHashmap, WeaponDataComponentData,
ProjectileWeaponComponentData, ProjectileSettings/DamageSettings/DamageInfo,
ArcWeaponComponentData/ArcSettings, BeamWeaponComponentData/BeamSettings,
SprayWeaponComponentData, MeleeWeaponComponentData, WeaponRoundsComponentData,
OrbitalAbilityComponentData, HealthComponentData including 38 zones,
ShieldComponentData, HellpodPayloadComponentData, StratagemInfo,
RechargeComponentData and JumppackComponentData. Support is intentionally limited
to audited resource/field combinations in `domains/catalog.lua`.

These offsets and layout records are private implementation details. New builds
must be audited and pinned explicitly; failed validation must never auto-learn
an offset or promote a nearby matching number into a public field.
