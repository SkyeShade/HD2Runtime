# Live evidence

Generated by `scripts/generate_live_evidence.py` from `schemas/live_evidence.json`, the one place in-game test results are recorded. The public copy is `sdk/LiveEvidenceCatalog.json`.

A capability family is **live-proven** only when a user-run in-game test showed the intended effect. Only live-proven families drop `allow_unverified_effect`, and only within the scope below. Their fields carry a `liveEvidence` reference in their own capability catalogs. Tests that were not run or were inconclusive leave the family offline-proven. A live failure withdraws exactly the tested scope.

Composition tests record four separate facts: the donor output works, the reference write succeeded, the host reads the reference, and the gameplay output changed. A failed host is host-path evidence, never evidence against the donor output.
