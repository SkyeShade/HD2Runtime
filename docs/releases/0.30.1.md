# HD2Runtime 0.30.1 — Public lobbies allowed (warnings only)

0.30.1 changes one thing: **HD2Runtime no longer blocks Public matchmaking.** In 0.30.0 the Runtime switched a Public
lobby privacy setting to Friends Only and cancelled Quickplay. Now it only warns.

## Matchmaking safety: warnings only

- **Public privacy is allowed.** When this machine's lobby privacy is Public, or a lobby it hosts advertises Public, the
  Runtime writes one log line and shows the safety notice (top right): *Lobby privacy is Public: strangers can join.*
  It warns again only after the lobby has been non-Public and then becomes Public again.
- **Quickplay is allowed.** Each Quickplay run gets one log line and one notice: *Quickplay joins public games with
  strangers.*
- **SOS Beacon:** warned about as before.
- **Nothing is changed or called.** The game's privacy setter and Quickplay stop are no longer called, so the native
  call adapter is never created. Friends Only, Invite Only, Friends and Clan, offline and singleplayer get no warning,
  as before.
- If the game build's pins do not match, one log line says the warnings are unavailable. No notice is shown, because
  nothing is blocked either way.

The startup log says `MATCHMAKING SAFETY ACTIVE (warnings only)`. The 0.30.0 enforcement code is unchanged and still
tested; it is off by default (`ENFORCE=false` in `runtime/matchmaking_safety.lua`).

**What this means in play:** players without HD2Runtime, or with other mods, can join a Public lobby. Mods change the
game only on the machine that runs them, and host-decided systems (for example enemy spawns) follow the host. Custom
stratagems keep their 0.30.0 multiplayer rules: a lobby whose custom-stratagem registries do not match disables them
and locks the custom slots. Use Friends Only or Invite Only to play only with compatible Runtime users.

## Compatibility

- No API, field, schema or SDK content change. Mods built for 0.30.0 work unchanged, and `min_version` stays `0.30.0`
  for anything new in 0.30.0.
- The startup line reads `HD2Runtime 0.30.1 initialized (API 1)`. The SDK metadata reports 0.30.1.
- Not live-tested yet. The warnings use the same reads as 0.30.0's live-tested matchmaking safety, but nothing is
  called now. They are covered by the offline tests (`tests/test_matchmaking_safety.py`, `WarningsOnlyTests`).
