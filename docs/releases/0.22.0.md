# HD2Runtime 0.22.0

HD2Runtime 0.22.0 adds guarded deployed-entity authoring for 10 sentries, four conventional emplacements, and the deployment entities of four mine stratagems. The semantic graph separates each stratagem definition, deployed entity, mounted weapon, and attack branch while reusing the existing projectile, DamageInfo, explosion, status, beam, arc, magazine, rounds, and heat primitives.

All 18 deployment entities expose exact-baseline health and armor fields backed by uniquely owned reviewed component records. Twelve mounted weapons expose the safely resolved subset of ammo, fire rate, heat, projectile, damage, explosion, beam, arc, and status fields. Mine instances, triggers, distribution, targeting mechanics, deployed lifetime, projectile lifetime, and penetration slowdown remain blocked where native ownership is not proven.

The schema-v2 stratagem capability catalog publishes one canonical entry for each internal promoted descriptor, with opaque physical backing identities, separate target-specific operation groups, reviewed shared scopes, and plan metadata. Four proof projects exercise the public API and are built without deployment: `AntiTankEmplacementProof`, `ConventionalSentryProof`, `ExplosiveSentryProof`, and `UnusualSentryProof`.

See the [defensive authoring report](../HD2Runtime-0.22-defensive-report.md) and [stratagem capability catalog](../../sdk/StratagemAuthoringCapabilities.json).
