# HD2Runtime 0.22.1

HD2Runtime 0.22.1 is a metadata-only release. Runtime write semantics, guards, and target types are
unchanged from 0.22.0.

Both `SupportWeaponAuthoringCapabilities.json` and `StratagemAuthoringCapabilities.json` now publish
explicit support-weapon <-> call-in stratagem linkage:

- Stable semantic IDs for every support weapon (`weapons[].semanticId`) and every stratagem
  (`stratagems[].semanticId`).
- A forward link on each support weapon (`linkedStratagem`) and a reverse link on each support
  stratagem (`delivers`).
- A shared `supportCallInLinks` collection with a `relationshipId` merge key, provenance, and a
  reference-only delivery graph.

The links are proven through the native payload and hellpod-rack graph, never through display names.
The audit reports 35 support weapons, 32 known bidirectional links, 3 unresolved links (SG-88 and
CQC-72 have no call-in; C4's delivered object is unproven), and 0 mismatches. MS-11 Solo Silo is
fully named and reversible. The seven ambiguous weapon roots keep their call-in links, and their
weapon writes stay blocked.

See [support call-in linkage](../support-weapon-api.md#support-call-in-linkage).
