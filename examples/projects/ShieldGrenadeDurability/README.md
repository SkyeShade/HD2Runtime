# ShieldGrenadeDurability

Doubles the G/SH-39 Shield's health (1000 to 2000) and widens it from 1.8 m to 2.5 m.

The thrown device owns its ShieldComponent (unique owner), so both fields are one throwable-local transaction. They are the same members as the SH-32 shield relay's radius and health.

Requires allow_unverified_effect because no throwable edit is gameplay-proven. Built only; never deployed or launched.
