# EnemyArmorZoneTest

Live test: Charger head armor 4 -> 1.

**Result: live-proven (2026-09-29).** Liberator and Stalwart light-penetration shots damaged the Charger's head
instead of bouncing; other armored areas still behaved armored. Enemy damage-zone armor (`zone.armor` on enemy
classes) is live-proven.
