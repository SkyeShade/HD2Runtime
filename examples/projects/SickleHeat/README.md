# SickleHeat

Opt-in gameplay validation for guarded LAS-16 Sickle heat storage, cooling, and spare heatsink fields.

Requires Bingus Shared Loader v15+ / API 1 and HD2Runtime 0.18.0+ / API 1 installed once. This project contains only gameplay declarations and is not deployed or launched by the HD2Runtime build.

Build with `python build.py`. The result contains the gameplay mod only; HD2Runtime remains an external dependency.
