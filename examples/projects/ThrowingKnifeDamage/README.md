# ThrowingKnifeDamage

Raises the K-2 Throwing Knife's direct-hit damage from 300 / 150 to 450 / 225 and the number carried from 20 to 30.

The knife has no explosion. Its hit damage is the DamageInfo row its StickyComponent names, so standard and durable damage are one transaction. The carry count is the knife's own ThrowableComponent.

Requires allow_unverified_effect because no throwable edit is gameplay-proven. Built only; never deployed or launched.
