# ArmedResupplyTurret

Raises the Armed Resupply Pods turret's fire rate from 640 to 900 rpm and its magazine from 140 to 300 rounds, through the typed booster API. Each write re-proves the native chain live: Resupply stratagem booster entry, entity delta, hellpod rack slot, turret entity. Requires allow_unverified_effect because no booster edit is gameplay-proven. Built only; never deployed or launched.
