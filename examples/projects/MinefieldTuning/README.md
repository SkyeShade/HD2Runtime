# MinefieldTuning

Live test: widens the MD-6 Anti-Personnel Minefield mines' explosion (outer radius 5 → 8 m) and raises its damage (700 / 700 → 1000 / 1000).

The row is the explosion the MD-6 deployer's MinefieldComponent names; each contact mine's own ExplosiveComponent names the same row. It is a global settings row, so `allow_shared` is required.

Expected in game: mines from this stratagem kill in a visibly larger radius. Built only.
